ELEMENTAL STAFF — Minecraft Java 1.21.11 / Fabric

Controls
- Right-click: Meteor.
- Sneak + right-click: Tsunami.
- Cooldown: 5 seconds.

Destructive effects
- Meteor: large in-game explosion at the block/entity you are looking at.
- Tsunami: six broad impact bursts travelling forward, with water particles.
- Both effects damage entities and can destroy terrain.

IMPORTANT
These abilities permanently alter the Minecraft world. Back up your world first.
The tsunami is implemented as a series of destructive impact bursts with a water
particle effect; it is not a physically simulated moving water volume.

Requirements
- Minecraft Java 1.21.11
- Fabric Loader 0.18.4 or newer
- Fabric API 0.141.4+1.21.11
- Java 21 JDK to build

Build
1. Open this folder in IntelliJ IDEA or another Gradle IDE.
2. Let Gradle sync and download dependencies.
3. Run the Gradle task: build
4. The mod JAR will be in build/libs/.

Install
Copy the generated .jar into your CurseForge profile's mods folder.
This ZIP contains source code, not a precompiled .jar.
